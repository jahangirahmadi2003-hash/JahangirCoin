### 1. Official Identity

- **Project Name:** JahangirCoin

- **Initial Budget:** Zero-budget development wherever possible

### 2. Project Vision

JahangirCoin aims to build a recognizable meme-coin brand with a consistent identity, transparent documentation, an accessible website, and a community-driven growth strategy.

The project will be developed in stages. No exchange listing, market price, profit, or future success is guaranteed.

### 3. Brand Rules

The following details must remain consistent across project files and official communications:

- Official name: JahangirCoin
- Official ticker: JAH
- Official spelling: JahangirCoin
- Founder name: Jahangir Ahmadi
- Visual identity: Consistent logo, typography, and colors
- Website and social media: Use the same project identity

Do not change these details without an explicit project decision.

### 4. Development Principles

1. Prefer free and open-source tools.
2. Keep the code organized and easy to maintain.
3. Document important changes.
4. Never publish private keys, passwords, recovery phrases, or API secrets.
5. Test the website before publishing.
6. Review smart contracts before deploying them.
7. Never claim an audit has occurred unless it has actually been completed.
8. Never promise investment returns or guaranteed profits.
9. Do not deploy a token until its blockchain, supply, distribution, and costs are documented.
10. Keep a record of completed and pending tasks.

### 5. Tokenomics Status

The final tokenomics have not yet been approved.

The following decisions must be documented before deployment:

- Blockchain network
- Total token supply
- Initial distribution
- Founder allocation, if any
- Community allocation
- Liquidity allocation
- Vesting and lock-up arrangements
- Transaction fees, if any
- Contract ownership and administrative permissions

No supply or allocation figure should be treated as final until it is explicitly recorded in the approved tokenomics document.

### 6. Website Plan

The website should include:

- Home page
- Project introduction
- Tokenomics
- Roadmap
- Community links
- Risk disclosure
- Frequently asked questions
- Contact information

The website must clearly distinguish planned features from features that are already operational.

### 7. Social Media Plan

All official profiles should use the same name, logo, ticker, and project description.

Content should focus on:

- Project development updates
- Community participation
- Original memes
- Transparent announcements
- Website and documentation updates

Never publish fake partnerships, fabricated user numbers, false exchange listings, or misleading investment claims.
